## ملاحظات

- هذه الإضافات محوّلة من [CloudStream arprov](https://github.com/ramailo1/arprov) الأصلي (Kotlin) إلى TypeScript متوافق مع SkyStream
- بعض المواقع قد تكون محظوفة بـ Cloudflare ولاتعمل بشكل كامل
- الإضافات تحتاج تطبيق SkyStream لتعمل
